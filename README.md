# Exploratory Data Analysis Tool

This repository contains a Python-based Jupyter Notebook focused on performing **Exploratory Data Analysis (EDA)** and handling data exports efficiently.

## 🚀 Features & Workflow
* **Data Cleaning:** Handling missing values, duplicates, and data type conversions.
* **EDA:** Visualizing distributions, correlations, and key patterns in the dataset using `pandas`, `matplotlib`, and `numpy`
* **Data Export:** Exporting processed and cleaned data into clean CSV formats for downstream analysis or reporting.

## 🛠️ Technologies Used
* **Python**
* **Jupyter Notebook**
* **Pandas / NumPy**
* **Matplotlib
